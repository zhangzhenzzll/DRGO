# DRGO Algorithm
![MATLAB](https://img.shields.io/badge/MATLAB-R2020a%2B-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

The official MATLAB implementation of the **Dynamic Research Group Optimization (DRGO)** algorithm. 

This repository contains the source code used to generate the benchmark results in our manuscript. For the sake of strict reproducibility, the code utilizes a deterministic random seed based on the function number and run index.

## Quick Start
1. Open the project in MATLAB.
2. Run `main.m` to evaluate DRGO on the test suite. 
3. The statistical results will be automatically saved to `DRGO_Result_Metric.xlsx`.
